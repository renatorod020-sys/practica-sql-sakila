# Prácticas de SQL Inicial - Sakila Database

¡Hola, En este repositorio registro mis avances y ejercicios de práctica en MySQL Workbench, utilizando la base de datos de prueba **Sakila**.

## 🛠️ Herramientas utilizadas
* **Lenguaje:** SQL (MySQL)
* **IDE:** MySQL Workbench
* **Base de datos:** Sakila Sample Database

## 📌 Conceptos y Cláusulas Aplicadas
* `SELECT` y `FROM`: Selección y extracción de columnas específicas.
* `WHERE`: Filtrado de datos por condiciones exactas (cadenas de texto y números).
* `ORDER BY`: Ordenamiento de resultados ascendente (`ASC`) y descendente (`DESC`).
* `LIMIT`: Restricción y control de cantidad de registros mostrados (Rankings / Top N).

## 🚀 Próximos Pasos
* Aplicación de operadores lógicos (`AND`, `OR`).
* Manejo de rangos y listas (`BETWEEN`, `IN`, `LIKE`).
* Funciones de agregación (`COUNT`, `SUM`, `AVG`) y agrupamiento (`GROUP BY`).
